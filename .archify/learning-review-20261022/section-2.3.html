本节边界：本节看配置的完整规则怎样存进内存中的 records 数组，再按 ID 查找、修改和删除。每项包含 occupied 和 rule；index 帮助找到数组位置，worker 逐包匹配使用软件后端的 active 快照
固定示例

records[4] 保存 ID 20 的完整规则；order=[0,4,2,3] 对应 ID=[10,20,30,40]。删除 ID 20 后，再用位置 4 保存 ID 25；修改规则时检查并更新版本号

本节完整路径
规则安装成功 → 将完整内容存进 records 数组
按 ID 查找 → index 找到位置 → records[slot]
修改 → 检查版本 → 覆盖该项内容并分配新版本
删除 → 移除索引 → 清空记录 → 空位置再次使用
