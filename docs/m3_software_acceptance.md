## 已完成的软件能力

| 能力 | 当前交付 | 证据边界 |
| --- | --- | --- |
| 身份与拓扑 | 可信来源核对、UNKNOWN 语义、同交换域、别名与父子关系检查 | 构造身份与解析测试不能证明实际 PF/VF/SF 连线 |

| COUNT 与 AGE | 64 位计数有效位、有限预算老化轮询、精确删除及失败重试 | 真实流量续期和硬件回收仍需实机 |

| 持久与异常 | 正常清理、SIGKILL 封闭、精确重放、创建失败及旧句柄保护 | 未知硬件对象仍需独立清理证明 |
