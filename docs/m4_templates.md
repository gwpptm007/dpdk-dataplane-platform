# M4 模板表与原生 DPDK 适配

模板固定协议层次、匹配掩码、端口、方向、group、priority 和固定动作参数。
每流匹配值及显式标记为可变的动作参数在借用时填写；比较逐项语义字段，不比较填充字节。
范围和连接状态首期作为固定匹配集合，不能把范围上界解释成位掩码。

模板库有 64 个固定槽位，实例和每次借用都有不回绕的独立身份。
准备中、安装中或残留 flow 的引用都须持续持有借用凭据，重复归还和跨实例凭据拒绝。
每表容量和整个库的借用池均有界。调用串行化，关闭要求调用方停止使用且所有表已经清除。
此轮交付模板生命周期，后续队列负责在实际完成后归还引用，不能仅凭排队或超时提前归还。

创建先预留全局及端口模板配额；驱动分别返回 pattern、actions、table 三个句柄。
任一步失败都逆序清理。清理失败保留精确句柄和残留凭据，返回 `EUCLEAN` 及可恢复身份，
禁止借用残留模板。销毁重试只处理尚存在的句柄，实际清除完成才释放配额。

## 真实 API 与能力边界

24.11 适配调用实际 `rte_flow_info_get/configure`、pattern/actions template 和 template table API。
配置不自动重启端口、不切换 mlx5 模式，也不改变现有 M3 同步路径。
调用方须在 ethdev configure 之后、任何 flow 创建之前执行原生配置，并独占端口生命周期。
队列最多 8、深度最多 256，计数与老化资源按驱动返回上限预检，超限拒绝。
后续 [队列 AGE](m4_async_age.md) 已增加严格队列标志预检，配置成功后 AGE 通知只属于指定队列。

原生编译复用现有同步编译器，避免两套方向、网络字节序和指针生命周期语义分叉。
当前支持 ETH/IPv4/TCP/UDP/represented-port，以及 DROP、QUEUE、MARK、COUNT、AGE、represented-port。
每个匹配或动作仍须满足现有 IR 约束。共享间接动作绑定与其他动作类型留给后续功能，当前明确拒绝。
21.11 以及尚未明确适配的中间版本返回 `ENOTSUP`，没有退回同步 API 冒充原生模板。
PMD 是否支持仍由真实入口决定；成功编译和包装入口测试不代表实际设备已安装。
