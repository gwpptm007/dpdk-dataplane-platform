## 功能边界

- M2 的独立路由模式和 M4/M5 受管理端口对模式目前分别启动，逐项登记入口及能力，不能把存在的独立功能写成已经统一接入
- 队列与配额在线扩容、共享 RSS/METER、配置与规则混合事务仍按既有边界登记，不用这些扩展替代路线图生产化必需项
- 升级必须保留当前声明策略及持久请求历史，旧版本不兼容新格式时拒绝降级，不用旧快照覆盖新策略
- 多实例滚动升级与单实例短暂停机区别记录，不宣称没有验证过的无损转发、会话复制或自动流量接管
- 真实硬件卸载、CPU 旁路、物理热拔插及 DPU/网卡复位另列实机待验收，不用 TAP 或模拟冒充
