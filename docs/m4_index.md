# M4 稳定槽位索引与规模恢复

规则与 PMD 对象仍保存在固定槽位中，事务持有的对象地址不会因插入、删除或排序而改变。
新增索引只排序槽位编号，按规则 ID 和版本二分查找；空槽由空闲链表分配。
仓库分页从游标后二分定位并顺序复制，恢复时先校验完整输入，再建立索引和发布记录。
硬件后端同时索引新旧版本，释放前核对槽位身份，异常时隔离而不是释放其他版本。

查找为对数复杂度；中间插入和删除仍需移动连续的 32 位编号，并非任意顺序下常数复杂度。
索引不改变驱动操作、共享引用、补偿和未知句柄处理。控制入口也在驱动调用前拒绝版本耗尽，
避免安装成功后才发现账本不能发布；相同内容的幂等重放仍可返回未改变。
