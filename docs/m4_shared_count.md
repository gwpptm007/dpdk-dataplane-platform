# M4 共享 COUNT 与模板、异步队列联动

新增共享 COUNT 注册表复用正式 indirect COUNT 适配器，逻辑 ID 保持 64 位，实际绑定使用
PMD 返回的独立句柄。最多 64 个共享对象，每个对象在驱动调用前一起预留共享动作和物理计数器额度。
对象绑定到安装端口、域和精确 generation；删除再创建不能让旧引用自动指向新对象。

模板持有示例共享对象，逻辑 pin 和实际 flow 分别持有独立引用。动态动作槽可改绑其他共享对象，
固定槽仍核对原 ID 和版本。模板原生 mask 使用 COUNT 类型，实际动作使用 INDIRECT；
动作值由每个 flow 提供，不向 PMD 传入虚构的句柄掩码。

创建完成失败但返回了句柄时，仍须等待创建回执再删除。清理失败保留对象、配额、模板和共享引用，
隔离后按精确身份重试；未知结果不能通过普通重试强行清空。AGE 只释放规则引用，
不会删除仍由调用方管理的共享对象，也不会清零其累计计数。

所有 M4 原生模板、队列及共享对象调用共用 PMD 锁，避免不同组件并发进入不支持多线程的控制接口。
共享注册表引用的获取和释放位于 PMD 锁之外，避免锁顺序反转。服务独占自己的配置和队列，
不能与旧同步控制服务混用同一组写入资源。
